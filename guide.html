คู่มือวิทยากร · Facilitator Playbook

🎓 DIGITAL SURVIVAL

คู่มือใช้งานระบบสำหรับดำเนินกิจกรรมอบรม Digital Literacy · ~120 นักเรียน iPad · 2 ชั่วโมง

บทบาท 5 หน้าเตรียมก่อนงานวิธีรันวันจริง อ้างอิงปุ่ม Hostเคล็ดลับแก้ปัญหาหลังจบ

1 บทบาท 5 หน้า

เปลี่ยน yoursite เป็น URL จริงหลัง deploy

👦 นักเรียน

/index.html

แจก URL นี้ให้เด็ก · กรอกรหัสห้อง + ชื่อเล่น → เล่น

🎤 วิทยากร (Host)

/host.html

ล็อกอิน · คุมเกม (เริ่ม/ล็อก/เฉลย/ถัดไป)

📽️ จอฉาย (Presenter)

/presenter.html?s=รหัส

ต่อ projector · คำถาม/เวลา/podium/เสียง

🛠️ ผู้ดูแล (Admin)

/admin.html

วิเคราะห์ผล · ส่งออก CSV/XLSX · จัดการเซสชัน

2 เตรียมก่อนวันงาน

  1. Deploy ระบบขึ้น GitHub Pages แล้วจด URL จริง
  2. ตรวจ firebase-test.html ให้เขียวครบ 3 ขั้น
  3. เปิด host.html ล็อกอินได้ · admin.html ล็อกอินได้
  4. ซ้อมด้วย DEMO Mode — host กด "DEMO + 10 บอท" เล่นจบ 1 ภารกิจ ดู XP/leaderboard/เสียง/podium
  5. ทดสอบบน iPad จริง 2–3 เครื่อง (Safari) · เช็กปุ่มใหญ่พอ แตะการ์ดได้
  6. เตรียมสไลด์/กระดานเขียน URL + รหัสห้อง ให้เด็กเห็นชัด
  7. เช็ก Wi-Fi โรงเรียนรับ ~120 เครื่องพร้อมกัน (ระบบมี offline fallback แล้ว)

3 วิธีรันวันจริง (ทีละขั้น)

หัวใจของการดำเนินกิจกรรม — ทำตามนี้

  1. เปิด host.html → ล็อกอิน → กด "สร้างเซสชัน" (ไม่ใช่ DEMO) → ได้ รหัสห้อง
  2. เปิด presenter.html?s=รหัส บนเครื่องต่อ projector → กด 🎵 🔔 เปิดเสียง
  3. เขียน URL + รหัสห้อง บนจอ/กระดาน → ให้เด็กเปิดหน้าแรก กรอกรหัส + ชื่อเล่น
  4. ดูช่อง "เข้าร่วม" ที่ host ขึ้นครบ ~120 (จอฉายโชว์จำนวนผู้เล่น)
  5. แตะการ์ดภารกิจ (เช่น ภารกิจ 1) → เกริ่นนำสั้นๆ ด้วยปาก → กด ▶ เริ่ม
  6. เด็กตอบใน 30 วิ (จอฉายนับถอยหลัง + เสียง tick) → พอตอบครบ/หมดเวลา กด 🔒 ล็อก
  7. กด 📊 ผลลัพธ์ → จอฉายขึ้น เฉลย + แท่นคะแนน + คอนเฟตติ → อธิบายด้วยปาก
  8. กด → ถัดไป ไปข้อ 2, 3 ... จนครบภารกิจ (แต่ละภารกิจ 2–3 ข้อ)
  9. จบภารกิจ → แตะการ์ดภารกิจถัดไป ทำซ้ำ (ข้ามภารกิจได้ถ้าเวลาไม่พอ)
  10. ครบ 8 + Final Boss → กด "จบกิจกรรม" → เด็กเห็นหน้า Digital Survivor 🏆
⏱️ จัดเวลา 2 ชม. / 9 ด่าน ≈ 12–13 นาที/ภารกิจ — ถ้าช้า ข้ามบางภารกิจได้ (แตะการ์ดไหนก็เริ่มได้) · เน้นให้เด็กคิด+อภิปรายมากกว่าตอบเร็ว

4 อ้างอิงปุ่มควบคุม Host

▶ เริ่มเปิดคำถาม → เด็กเห็นตัวเลือก + timer เริ่มนับ
🔒 ล็อกปิดรับคำตอบ (กันตอบเพิ่ม) — กดเมื่อตอบครบหรือหมดเวลา
📊 ผลลัพธ์เฉลย + คิด XP + ขึ้นแท่นคะแนนบนจอฉาย
💡 เฉลยแสดงคำอธิบาย (ใช้ตอนอภิปราย)
→ ถัดไปไปคำถามข้อถัดไปของภารกิจนั้น
🏆 จบกิจกรรมปิดห้อง → เด็กเห็นหน้าสรุป Digital Survivor
✨ เซสชันใหม่เริ่มห้องใหม่ (เซสชันเก่าดูย้อนหลังได้ที่ Admin)

ปุ่มจะสว่าง/หรี่ตามจังหวะ — ระบบเปิดเฉพาะปุ่มที่ใช้ได้ในสถานะนั้น

5 เคล็ดลับการดำเนินกิจกรรม

🗣️
เกริ่นก่อนกดเริ่ม — เล่าสถานการณ์ให้เด็กอินก่อน แล้วค่อยกด ▶ เริ่ม
🤔
หลังเฉลย เปิดวงอภิปราย — "ทำไมข้อนี้ดีกว่า?" สำคัญกว่าตัวคะแนน (แนวคิดหลัก: ไม่มีถูก-ผิดตายตัว)
🏆
ใช้ leaderboard สร้างความสนุก แต่ย้ำว่าคะแนนมาจากคุณภาพการคิด ไม่ใช่ความเร็ว
⚖️
ภารกิจ 8 (สุขภาวะ) เป็นการสะท้อนตนเอง ไม่มีถูก-ผิด — ย้ำว่าเป็น Habit Profile ไม่ใช่การวินิจฉัย
🎬
Final Boss รวมทุกหัวข้อ — ใช้เป็นไคลแม็กซ์ ให้เด็กเรียงลำดับการตัดสินใจ

6 แก้ปัญหาเฉพาะหน้า

เด็กเข้าไม่ได้ "ไม่พบรหัสห้อง"เช็กรหัสให้ตรง (ตัวใหญ่) · ห้องยัง "เปิด" อยู่ไหม
หน้าจอเด็กค้างให้รีเฟรช (Cmd/แตะ refresh) — progress ถูกจำไว้ กลับเข้าได้เลย
เน็ตหลุดระบบขึ้นแถบเตือน + เก็บคำตอบไว้ ซิงก์อัตโนมัติเมื่อกลับมา
จอฉายไม่มีเสียงกดปุ่ม 🎵 / 🔔 มุมขวาบน 1 ครั้ง (เบราว์เซอร์ต้องมีการคลิกก่อน)
ตัวเลข "ตอบแล้ว" ไม่ครบปกติ — บางคนอาจยังคิด กด 🔒 ล็อก เมื่อพร้อม
host เผลอปิดแท็บเปิด host.html ใหม่ ล็อกอิน → เข้าเซสชันเดิมอัตโนมัติ

7 หลังจบกิจกรรม

  1. เปิด admin.html → ล็อกอิน → แท็บ เซสชัน → กด "เลือก" เซสชันวันงาน
  2. แท็บ วิเคราะห์ — ดูอัตราจบ · คะแนนเฉลี่ย · ภารกิจ/ข้อที่ตอบถูกน้อยสุด
  3. แท็บ ส่งออก — ดาวน์โหลด CSV / XLSX (Player ID · คะแนนรายภารกิจ · XP · เหรียญตรา)
  4. นำผลไปสรุป/ต่อยอดการสอน · เก็บถาวรเซสชันได้ที่แท็บเซสชัน

✓ ระบบไม่เก็บข้อมูลส่วนตัว (ชื่อจริง/เบอร์/บัตร) — เก็บแค่ชื่อเล่น·ห้อง·คะแนน
